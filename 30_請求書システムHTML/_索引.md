# 30_請求書システムHTML フォルダ 索引

## ★ 本番で使うファイル（最新版）
- **`Amazon真贋・アカウント統合管理システム_v11.html`** … これが最新の統合システムです。**普段はこれを開いてください。**（更新のたびに末尾の版番号が上がります: v7 → v8 → …）
  - 中身: Amazonアカウント台帳・苦情・真贋対策の総合管理 ＋ 請求書発行（本格版）を1ファイルに統合。
  - タブ: 1.ダッシュボード / 2.アカウント台帳 / 3.変更履歴 / 4.案件・苦情 / 5.請求書発行 / 6.対応・提出履歴（事案別スレッド）/ 7.顧客・代行
  - 主な機能:
    - 請求書の宛名（取引先）＝アカウント台帳を自動反映。発行元＝請求書の「宛元マスタ」で一元管理。
    - 対応・提出やり取りをAmazonとの往復スレッドで記録（発信/受信・日時・書類・結果・**提出ファイル名の自動生成**）。
    - 案件ごとに **Dropbox原本フォルダURL** を登録→「📂原本フォルダを開く」。
    - 顧客（委託元）マスタ・代行管理、絞り込み（全体/自社/顧客別）、検索、今週の期限、顧客別成果レポート、代行報酬の請求。
    - 各ページで **Excel/CSV 書出・取込**（追記/更新）。トップバーの「データ書出/読込」はJSON全体バックアップ。

## 素材・元データ（保管）
- `請求書発行システム_最新版.html` … 請求書アプリの旧単体版（統合前）。参考用。
- `請求書発行システム_vo3_メモ用.txt` / `請求書発行システム_フォーマット集対応vo1.txt` … 請求書アプリの過去メモ。
- `★19_請求書フォーマット_請求書一覧_統合済.xlsx` … 請求書フォーマットの元Excel。
- `Amazonアカウント台帳.xlsx` … アカウント台帳の元Excel。

## 命名規則（提出資料の原本・Dropbox保管）
- フォルダ: `案件{No}_{ASIN}_{アカウント}`（例: `案件1_C7GBPVB3_animalcompany1982`）
- ファイル: `{YYYYMMDD}_{書類種別}_{発信|受信}[_{補足}]`（例: `20260720_請求書_発信_中古コンディション`）
- アプリの「対応・提出履歴」タブで**ファイル名を自動生成**できます。

## 注意
- データはブラウザ内（localStorage）に保存。バックアップはトップバー「データ書出」（JSON）または各ページのExcel/CSV書出で。
- 請求書のExcel出力・xlsx取込はインターネット接続時のみ（ライブラリを外部から読込）。
- 旧統合版（vo1〜vo4）は v5 に統合済みのため削除しました（履歴はGitに残っています）。
