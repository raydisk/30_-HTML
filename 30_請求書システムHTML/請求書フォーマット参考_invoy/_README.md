# 請求書フォーマット参考（invoy・無彩色）

invoy（インボイ）の無料テンプレート集（全437ページ）から、**無彩色（モノクロ）**版を
デザイン系統ごとに整理した参考資料です。色は不要とのご要望のため無彩色のみ収録。
装飾系のうち **フレーム(レース)・イラスト(犬/猫/サボテン)** は対象外としています。

- 出典: invoy（https://go.invoy.jp/template/ ）
- これは**デザイン参考用の画像**です。invoy公式の配布Excel/Word等そのものではありません。
- 実運用で使う場合は invoy 利用規約（https://www.invoy.jp/legal/terms/ ）・商用利用条件をご確認ください。

## 共通レイアウトの特徴
- 中央または左上に大きな書類タイトル。宛名（御中）は下線付き。
- 右上に発行日／お支払い期限、右中に発行元ブロック＋角印。
- 明細表＝取引日／品目／**税率区分（※で軽減税率8%）**／数量／単価(税抜)／金額(税抜)、固定高さの空行つき。
- 合計欄＝**10%小計／8%小計／10%税額／8%税額／合計(税込)** を分離表記。
- 下部＝振込先・備考。Word版は発行元に **登録番号** 欄あり。

## 領収書の補完（自作）
invoy には**ベーシック明朝以外の領収書が存在しない**ため、請求書・納品書・領収書を
「同一デザインで3点セット」にできるよう、各系統の意匠（フォント・装飾帯）に合わせた
**領収書を自作**し、`05_領収書_補完.png` として各フォルダに追加しました（モノクロ）。

- 対象: ベーシックゴシック / シンプルモノトーン / フレーム4種（チェック・ドット・千鳥格子・和柄）/ イラスト(ビル街) の7系統。
- 内容: 領収書タイトル・宛名・領収番号/発行日・金額（税込）・但し書き・**内訳（10%/8%小計・税額）**・発行元＋角印・**登録番号**・収入印紙欄。適格簡易請求書（インボイス）の記載要件に配慮。
- 装飾は各系統の請求書に合わせた帯（チェック/ドット/千鳥格子/麻の葉風/ビル街シルエット）をモノクロSVGで再現。invoy公式の配布物ではなく当方の自作補完です。
- ベーシック明朝の領収書（`05_領収書.png`）は invoy 公式のもの。

これで **全8系統で 請求書・納品書・領収書 の3点が揃います**。

## 補足
- アプリ本体（統合管理システム）内の請求書書式は、別途 **モノクロ10種（P〜Y）** を実装済み。
  この参考フォルダは、そのデザイン検討のための素材であり、アプリの書式とは独立しています。
