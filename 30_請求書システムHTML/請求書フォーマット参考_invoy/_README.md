## デザインの特徴（請求書）
- 中央に「請 求 書」タイトル＋太い区切り線。
- 左上＝宛名（御中）に下線。右上＝請求日／お支払い期限。
- 左中＝件名・ご請求金額（税込）を大きく。右中＝発行元ブロック＋角印。
- 明細表＝取引日／品目／**税率区分（※で軽減税率8%）**／数量／単価(税抜)／金額(税抜)。空行を含む固定高さ。
- 合計欄＝**10%税率 対象小計／8%税率 対象小計／10% 税額／8% 税額／合計(税込)** を分離表記。
- 下部＝振込先（金融機関・支店／口座名義）と備考。
