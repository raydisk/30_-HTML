# ビジネス書類フォーマット集（自作・無彩色）

ビジネス間取引（B2B）向けの **請求書・納品書・領収書の3点セット**を、統一デザインで自作した
信頼できるフォーマット集です。**絵・イラスト・ポップ調は不使用、無彩色（モノクロ）**のみ。
会計ソフト各社（Misoca／freee 等）の標準的な記載構成に沿っています。

## 収録スタイル（各3点＝請求書・納品書・領収書）
| フォルダ | スタイル | 特徴 |
|---|---|---|
| `A_標準センター` | 標準・センター見出し（明朝） | 中央タイトル＋二重罫。もっとも一般的な体裁。 |
| `B_ミニマル左` | ミニマル・左見出し | 細罫と余白の実務的レイアウト。 |
| `C_総罫線グリッド` | 総罫線グリッド（台帳調） | 全体を罫線で囲んだ台帳スタイル。黒帯ヘッダー。 |
| `D_右上サマリー枠` | 右上サマリー枠 | 右上に金額・発行情報のサマリー枠。 |

- 各フォルダに、その3点をまとめた `_{スタイル}.pdf` を同梱。
- ルートの `自作ビジネス3点セット_全4スタイル.pdf` に全12点を1本化（スタイルごと・請求→納品→領収の順）。

## インボイス（適格請求書）対応の記載
すべての様式に以下を記載しています。
- **登録番号**（適格請求書発行事業者）
- **取引日**欄、**型番・JAN**（明細）
- **税率区分**（10%/8%）と**税率ごとの対象金額・消費税額**（区分記載）
- **軽減税率(8%)** の対象品目に「*」＋注記
- 請求書：お振込先／備考、領収書：内訳・収入印紙欄

## メモ
- 本フォルダは当方の**自作**（著作権フリー）。特定サイトの配布物の転載ではありません。
- サンプルの金額・住所・角印はダミーです。実運用ではデータ差し替え。
- アプリ本体（統合管理システム）内の請求書書式（モノクロ10種 P〜Y）とは独立した参考資料です。
  ご希望のスタイルはアプリの書式として実装も可能です。
